# 내 사진 쓰기

이 폴더에 가게 사진을 넣고 `--images-dir examples/images` 로 넘기면
스톡 사진 대신 실제 사진이 카드에 들어갑니다. 결과 품질 차이가 가장 큰 옵션입니다.

## 파일명 규칙

파일명에 키워드를 넣으면 해당 카드에 우선 매칭됩니다.

```
파스타_대표메뉴.jpg      -> image_keywords 에 "파스타" 가 있는 카드
성수동_외관.jpg          -> "성수동" 키워드 카드
01_라트라토리아.jpg      -> place 카드 01
```

키워드가 안 맞으면 남은 사진을 순서대로 씁니다.

## 권장 사양

- 세로 4:5 (1080×1350) 또는 그보다 큰 사진
- JPG / PNG / WEBP
- 카드 수만큼 넉넉히 (같은 사진이 두 번 쓰이지 않게 하려면)
